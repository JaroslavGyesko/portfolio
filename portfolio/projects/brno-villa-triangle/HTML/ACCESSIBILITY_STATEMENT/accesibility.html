    Accessibility statement

    SITE CONTENT

    This page was created for the MMB project. It is written in English and adheres to the grammar standards set out in the English Grammar Rules.

    STANDARDS

    The HTML5 language was used to create this page. Graphic styles were created and modified using Cascading Style Sheets (CSS). For better page transparency, a JavaScript element was also included for dynamic interaction with the visitor.

    COLOURS

    This page has text colors set to meet readability standards, however, it is possible to see places where readability may have some problems, which is why a "Toggle dark mode" button is included at the bottom of the page

    IMAGES

    All images that have been added to the page are in .jpg, .png format. They are of high quality and also have alternative text defined in case they cannot be loaded from the server.
